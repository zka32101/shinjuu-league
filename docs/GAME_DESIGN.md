## 🌍 世界観・テーマ

### コンセプト
**「二つの大陸、相対する神獣。短時間で決着がつく奇跡の戦い」**

### 舞台設定
- **火炎大陸（東）**: 太陽が輝く熱き大陸。神獣たちは本能のまま火力を求める
- **氷雪大陸（西）**: 月が照らす冷たき大陸。神獣たちは知恵と支援で戦う
- **神聖なる闘技場**: 二大陸が召喚した古代の闘技場。ここで5分間の決戦が繰り広げられる

### トーン
本気の戦い × 祭りの興奮。派手さと緊張感の両立。

**KPI軸**:
- **Day7 リテンション: 40%** — 短時間でも本気感がある
- **Aha Moment（初キル）: 即座に検知** — 神獣の力解放を演出

### キャラクター詳細

#### 1. 火炎獅子 レオン (COMMON・タンク)

**役割**: 敵陣への突入・味方の前衛盾

**特性**:
- 高HP・高防御、移動遅い
- 敵の集中砲火を受けることで活躍
- 序盤からタンク役として機能

**ロール**: イニシエーター型

**推奨進化選択**:
- 攻撃型: 火力も欲しい場合
- 防御型: 序盤から硬さを極める（推奨）
- 支援型: 味方をサポートしながら前衛

---

#### 2. 烈風鷲 ウルフ (RARE・DPS/ユーティリティ)

**役割**: 敵DPSの排除・移動支援

**特性**:
- 中程度火力・素早い
- 柔軟な立ち回りが可能
- 進化選択で火力/防御/支援に分岐

**ロール**: ユーティリティDPS

**推奨進化選択**:
- 攻撃型: 安定した削り火力
- 防御型: キャリーの前衛補佐
- 支援型: 味方の機動力を上げる

---

#### 3. 地煞龍 ドラグーン (LEGENDARY・キャリー)

**役割**: 試合全体の火力支柱・終盤の主役

**特性**:
- 低火力スタート → 徐々に覚醒 → Lv8で超高火力
- Lv5以降の真龍状態で無制限火力
- 「育成できるかどうか」で試合が決まる

**ロール**: スケーリング型キャリー

**推奨進化選択**:
- 攻撃型: 火力を徹底的に追求（推奨）
- 防御型: タンクと組み合わせで生存を目指す
- 支援型: チームゲームに特化

---

#### 4. 氷盾熊 フロスト (COMMON・サポート)

**役割**: 味方の生存確保・敵の速度低下

**特性**:
- 中HP・盾生成特化
- 敵のCC効果を無視する防御型
- 全試合で活躍可能な安定性

**ロール**: シールドサポート

**推奨進化選択**:
- 攻撃型: 盾にもダメージを付与
- 防御型: チーム全体の防御を極める（推奨）
- 支援型: 味方全員に盾配布

---

#### 5. 烈火鷲 フェニックス (RARE・DPS)

**役割**: 敵キャラの高速削減・群れへの対抗

**特性**:
- 高攻撃・素早い・低防御
- 連続攻撃で敵を圧倒
- 序盤からDPS役として活躍

**ロール**: 物理DPS

**推奨進化選択**:
- 攻撃型: 連射を活かした火力（推奨）
- 防御型: 自盾で生存性を上げる
- 支援型: 敵デバフで味方をサポート

---

#### 6. 星魔姫 クリスタル (LEGENDARY・コントローラー)

**役割**: 敵の行動禁止・チーム戦の支配権確保

**特性**:
- 低HP・高魔力・遠距離特化
- CC（Crowd Control）能力が業界最強
- Lv7以降のULT（次元裂き）で試合決定

**ロール**: CC型コントローラー

**推奨進化選択**:
- 攻撃型: Q連鎖で敵を圧倒
- 防御型: 魔法耐性を高める
- 支援型: デバフで敵を弱体化（推奨）

## ⚔️ スキルシステム

### 基本構成（全キャラ共通）

```
Q: 基本攻撃スキル
  ├─ Lv1/3/5/7で段階強化（ダメージ増加 or 追加効果）
  └─ クールタイム: 4秒

R: 中スキル
  ├─ Lv2/4/6/8で段階強化（範囲拡大 or CC追加）
  └─ クールタイム: 8秒

E: 進化スキル
  ├─ Lv3: 進化選択① (攻撃型/防御型/支援型) ← 分岐A
  ├─ Lv6: 進化選択② (現在の進化を強化 or 切り替え) ← 分岐B
  └─ Lv8: 最終進化 (すべての進化方向が最大火力に)

ULT: 必殺技
  ├─ Lv5: チャージ開始（準備状態）
  ├─ Lv7: 解放完了（使用可能）
  ├─ Lv8: 強化版解放（さらに威力UP）
  └─ クールタイム: 45秒
```

### 進化選択システム

#### 進化選択① (Lv3)

| 選択 | 効果 | 説明 |
|------|------|------|
| **攻撃型** | ダメージ+60% | Q/Rの火力を徹底的に強化。敵の排除に特化 |
| **防御型** | HP+30%, 軽減+20% | 生存能力を極める。タンク的な立ち回り |
| **支援型** | 味方効果+50% | 敵デバフ/味方バフを強化。チーム戦特化 |

#### 進化選択② (Lv6) — 中盤の戦況判断

| 選択 | 効果 | 使用場面 |
|------|------|----------|
| **進化維持** | さらに+40% | 現在の方向性が上手くいっている |
| **進化切り替え** | 別の進化に変更 | 敵チームの構成に対応する |

例: 攻撃型で開始 → 敵が火力特化 → Lv6で防御型に切り替え

#### Lv8：最終進化
```
すべての進化方向が最大火力に到達
  攻撃型: ダメージ+100% (Lv3時+60% → Lv6時+100% → Lv8時+150%)
  防御型: 軽減+50% (完全なタンク形態)
  支援型: 効果+150% (チーム全体を支配)
```

## 🎮 ゲームメカニクス

### ゲームループ（5分 = 300秒）

```
0:00 - ゲーム開始
  ├─ Lv1で開始
  ├─ 敵キャラとの自動遭遇開始
  └─ 初キル発生 → Aha Moment検知 & 演出

0:38 - Lv2到達
  └─ Rスキル解放

1:15 - Lv3到達 ★進化選択①
  ├─ 攻撃型/防御型/支援型から選択
  └─ キャラの方針が決定

2:30 - 中盤
  ├─ Lv4-5到達
  ├─ ULT チャージ開始（Lv5）
  └─ チーム連携本格化

3:45 - Lv6到達 ★進化選択②
  ├─ 現在の進化を強化 or 切り替え
  └─ 敵チーム構成への対応判断

4:30 - 終盤
  ├─ Lv7到達
  ├─ ULT解放完了（使用可能）
  └─ 必殺技による大型団戦

5:00 - ゲーム終了
  ├─ 敵全滅 or 時間終了
  └─ スコア算出（敵撃破数・ゴールド・ULT命中数）
```

### ゲーム進行システム

#### 敵キャラとの自動遭遇
```
自動マッチング（Matchmaking Service）
  ├─ 自分の敵は「5人の実ユーザー」or「Bot」の混合
  ├─ 味方（4人）も同様に実ユーザー+Bot
  └─ ELOレーティングで適切なレベルの敵を自動選出
```

#### レベルアップシステム
```
敵キャラ撃破時:
  ├─ 経験値 +20（1体撃破ごと）
  ├─ ゴールド +50（1体撃破ごと）
  ├─ 自動でLvアップ（38秒ごと）
  └─ スキル威力 & 進化ポイント自動付与
```

#### 進化選択画面
```
Lv3到達時:
  ├─ 画面に3択が表示される
  ├─ 10秒でタイムアウト（デフォルト: 攻撃型選択）
  └─ 選択完了で E進化スキル有効化

Lv6到達時:
  ├─ 2択が表示される（進化維持 or 切り替え）
  ├─ 10秒でタイムアウト
  └─ 戦況に応じた柔軟な選択が可能
```
